# 박물관의 황혼 · 여월의 밤 v5

박물관의 기억을 정화하는 탑다운 액션 RPG입니다. 기존 6개 시대의 전투와 시나리오를 연결 맵, 저장 슬롯, 의뢰와 분기 대화로 확장했습니다.

## 시작

`npm start` 후 http://127.0.0.1:5173 접속합니다. Python이 필요합니다. Node가 설치된 환경에서 `npm test`, `npm run build`를 실행하면 검증과 dist/ 생성을 할 수 있습니다.

일러스트 시작 화면 터치 → 캐릭터 메인 로비 → 안내 데스크 방문 / 학예사 등록 / 밤의 전시실. 이어하기와 조작법은 환경설정에서 엽니다. 기존 v2 기록은 빈 슬롯에서 선택적으로 가져올 수 있습니다.

## 추가된 RPG 기능

- IndexedDB 3개 슬롯, 좌표·스탯·인벤토리·장착 유물·월드 플래그·방 상태·퀘스트·복원도 저장
- 안내 데스크와 수장고 텐트 자동 저장, 사망 시 체크포인트 로드, JSON 백업 내보내기/가져오기
- 24개 JSON 타일 방, 충돌과 적 우회 이동, 페이드와 스폰 매핑, 스위치·능력 게이트, 이전 기록실 재방문
- 20개 의뢰의 조건 트리, 선행 의뢰와 중복 보상 방지, 낮/밤 대화와 선택 플래그
- 시온/하연 선택. 하연은 생명 85·정화력 24·이동 112%·자기꽃 산탄으로 시작하며 기존 시온과 같은 스타일의 새 20프레임 애니메이션을 사용합니다.
- 6구역 정화 후 다음 회차. 캐릭터·복원도·정산 파편을 계승하고 월드·의뢰·능력을 초기화합니다.
- C# GZip/SHA-256 오프라인 백업 모듈과 CLI. 클라우드 동기화 서버는 연결하지 않았습니다.

Node 테스트 49개가 통과했습니다. 기존 IndexedDB 및 .NET 압축 검증에 더해 일러스트 대화의 선택·완료 처리와 난이도 상승을 검증합니다. 브라우저 저장 테스트는 /tests/browser-save.html 에서 별도 임시 DB로 실행할 수 있습니다.

유물 전시대를 조사하면 주인공(왼쪽)과 도윤 선임 학예사(오른쪽)의 선택형 일러스트 대화가 열립니다. 마지막 기록 버튼을 눌러야 관찰이 인정되며, 의뢰 일지에서도 설명을 다시 들을 수 있습니다. 안내 데스크의 도윤 NPC를 눌러 상담하고 낮에 기록실 의뢰를 보고하세요.

초반 기본 적 체력은 78, 첫 보스 체력은 510입니다. 새 회랑의 적은 5마리부터 시작해 구역마다 늘어납니다. 구역·정화 수·회차에 따라 체력과 공격력이 상승하고 공격 간격이 줄어들며, 후반 원거리 적은 3방향 탄막을 사용합니다. 기존 방의 적은 남은 체력 비율과 처치 기록을 유지합니다.

현재 콘텐츠는 24개 방·20개 의뢰·캐릭터 2명입니다. 방은 기존 6개 배경 아틀라스를 공유하며 타일 장애물과 포털, 저장 상태가 다릅니다. 상용 게임 수준의 수십 시간 콘텐츠 분량이나 실제 휴대폰 장시간 성능을 검증한 것은 아닙니다. APK/AAB/IPA 서명과 스토어 배포도 별도 단계입니다. 박물관 도록은 기획서 기반 창작 해설이며 공식 소장품 아카이브가 아닙니다.

도윤 NPC는 주인공과 같은 SD 비율의 보랏빛 복장으로 제작했습니다. 전시물은 유리관 없는 낮은 받침대 형태입니다. 회랑의 적을 처치할 때마다 유물 조각이 모이고, 전멸 후 조사 대화를 완료하면 복원이 완성됩니다. 조사 전 이탈해도 처치 기록으로 부분 복원 상태를 복구하며, 완료 기록은 기존 저장 데이터에 유지합니다.
