# 도윤 학예사와 유물 조사

IllustratedDialogue는 조사·의뢰 설명·안내 데스크 상담을 공통 대화 화면으로 표시합니다. 선택한 주인공의 로비 일러스트를 왼쪽에, 도윤을 오른쪽에 두고 현재 화자를 밝게 표시합니다. 유물별 관찰 문구와 전시 주제를 바탕으로 한 창작 대화를 함께 제공합니다.

조사는 마지막 페이지를 완료한 시점에만 기존 recordObservation을 호출합니다. 중간에 닫으면 관찰 수가 늘지 않습니다. 선택지는 후속 응답을 삽입하고, 데스크의 태도 선택은 기존 world.choices에 기록합니다. 완료 시 EventBus의 talk/choice 이벤트를 전달하므로 기존 낮 시간·보고 순서·보상 중복 방지 조건을 사용합니다. 기존 점동이 대화로도 의뢰를 진행할 수 있습니다. 페이지는 타이머 없이 교체하며 캠페인 종료 시 세션 토큰을 무효화합니다.

난이도 값은 js/data/difficulty.js에 모았습니다. 구역 단계, 정화한 구역 수, 회차가 입력입니다. 방에 다시 들어갈 때 기존 적의 남은 체력 비율을 새 최대 체력에 적용하며, 처치한 ID는 재생성하지 않습니다. 이미 저장된 방의 적 수는 유지되고 새 방에는 확장된 배치가 적용됩니다.

검증: Node 47개 테스트 통과. 실제 브라우저에서 저장 슬롯 이어하기, 데스크 NPC 대화, 선택지 후 복귀, 의뢰 설명 연결을 확인했습니다. 844×390 모바일 가로 화면 및 1280×720 PC 화면에서 대화 레이아웃을 확인했습니다. 장시간 플레이의 체감 난이도는 추가 플레이테스트로 조정할 수 있습니다.

이미지: ImageGen으로 제작한 도윤의 전신 일러스트와 작은 NPC용 캐릭터 PNG. 짙은 남색 의복, 회색이 섞인 머리와 수염, 안경, 전시 기록 책을 공통 모티브로 사용했습니다. 배경 제거 편집 후 알파 투명 PNG를 런타임 및 오프라인 빌드에 포함했습니다.
